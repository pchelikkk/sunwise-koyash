## Included in this release

- integrated React SPA and FastAPI backend through a typed API client;
- single-port production deployment via nginx reverse proxy (no CORS);
- live questionnaire, recommendations, feedback/replacements, authentication, account,
  and history flows;
- analytics event ingestion endpoint;
- architecture documentation (static / dynamic / deployment views + ADRs);
- development process and configuration management documentation;
- extended backend tests and CI coverage;
- updated quality requirements, quality requirement tests, testing docs, and DoD;
- UAT scenarios UAT-01..05 and customer UAT / Sprint Review evidence;
- Week 5 report artifacts.
